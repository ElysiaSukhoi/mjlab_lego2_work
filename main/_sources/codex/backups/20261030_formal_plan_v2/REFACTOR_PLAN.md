## 阶段1：独立任务与盲走观测

**修改范围**

- 新建独立配置入口，候选名 `Mjlab-Blind-Pit-Lego2`，不覆盖旧 Platform-Climb。
- 为新任务显式配置 actor：角速度、重力投影、关节状态、上一动作和速度命令，
  移除 height_scan/地形坐标/目标平台位置，真实线速度不直接作为 actor 输入。
- 加入约5帧的本体历史；先用普通历史堆叠＋原PPO/MLP，不直接移植完整DreamWaQ/VAE。
- critic 可保留高度扫描和其他训练特权观测；这些信息不进入部署actor或其历史。
- 保持12维动作、动作缩放、控制频率、PPO损失和网络隐藏层等基本设置，暂不同时调算法。
- 对新任务的注册、观测配置使用独立对象，验证不会改变旧任务的观测维数。

**验收**

检查配置与实际actor输入；历史维数和reset清零正确，批量reset不会把上个episode历史带入；
旧任务能正常加载。只做编译、配置和少量环境检查，不长训。

**影响**

观测维数改变，旧checkpoint不能直接续训；新任务从新run初始化。此处只保留原PPO框架，
不承诺历史堆叠本身就能复现DreamWaQ的性能。

## 阶段2：中央坑、坑底出生、指令与高度课程一起接通

**修改范围**

- 复用现有 `BoxInvertedPyramidStairsTerrainCfg`，生成中央单级坑，避免误生成多级台阶。
- env origin 位于坑底，reset基于该origin，不再额外减一次坑深；禁止随机出生在坑沿。
- 初版采用正向移动和有限出生扰动，集中验证出坑动作；全向指令与随机朝向后续再扩展。
- 从第一次正式训练开始启用高度课程，初始只分配最低等级，成功后升级、失败后降级；
  保留较容易样本，防止只留最高难度。
- 距离作为课程升级主依据，但要联合坑几何、机身包络与跌倒状态核查，避免角落未出坑
  或翻倒滑出被误认为有效通过。

**建议起始参数（实施前仍需几何/运行验证，不是已确认最优值）**

| 项目 | 候选设置 |
| --- | --- |
| 地块 / 坑底 | 10×10 m / 中央3×3 m，复用已有单级坑组合 |
| 初始训练高度范围 | 0.03～0.30 m，10级，初始等级0 |
| 平移命令 | vx约0.3～0.6 m/s，vy=0；朝向保持使用已有命令机制 |
| episode | 暂沿用20 s，并与行程检查匹配 |
| 升级距离 | 距坑中心约3 m作为候选；不机械复用地块一半的5 m |

3×3 m方坑的半对角线约2.12 m；3 m候选阈值需进一步确认可让机身/轮足整体通过。
距离升级线不能要求机器人在低速指令下几乎无停顿地跑完整个episode。
300 mm沿用此前目标作为首个训练上限参考，不把其他机器人80 cm演示直接当Lego2目标。

**验收**

从生成几何核对各级坑深/台面；重复reset都在坑底、无穿透；用合成状态验证升降级、
首次reset、最高级和跌倒场景；Viser抽查几个等级。此阶段不以策略表现评价几何正确性。

## 阶段3：精简奖励、评估指标和第一轮短训

**修改范围**

- 新任务不注册旧的 `platform_approach`、`platform_edge_lift`、`platform_front_lift`、
  `platform_front_contact_advance`、`platform_top_bonus`。旧任务源码保留供回滚对照。
- 移除旧平台坐标限定的成功终止；保留超时、翻倒/非法接触、越界等基本终止。
- 以现有线速度/角速度跟踪为主，配少量必要的姿态、动作变化、关节限制与能耗正则，
  轮腿分别处理；先核对函数定义、坐标、dt与动作尺度，再定权重。
- 默认腿姿态、固定机身高度、强制多轮贴地和侧壁碰撞代价不能共同把必要抬升压死。
  初版不强制固定世界机身高度；已有air-time/clearance不因名字合适就直接开启。
- 几何通过、台沿有效支撑、稳定保持、跟踪误差、停滞、跌倒和各高度成功率保留为
  **评估指标**，不全部变成训练奖励；高度与净空必须区分轮心和轮底。
- 初期随机化保持克制，资产/动作/PPO设置冻结，便于定位奖励与课程的影响。

**验收与训练**

先完成本地合成数值/配置/小环境验证，再给远程同步和校验指令。
第一次远程短训就开启第2阶段的高度课程：

- 约128～256环境、200～500 iterations可作流程冒烟，检查数值、reset、显存与记录。
- 流程稳定后约1024～2048环境、1000～3000 iterations观察低阶通过与课程趋势；
  具体规模按当时显存决定，不把这些轮次当收敛保证或成败硬阈值。

验收重点是最低级有真实通过、没有明显平地无意义抬轮、没有奖励增大却原地不动，
以及课程升降是否与回放一致。若最低级也失败，先核查接触、驱动、动作与定义，
不直接用更多样本或更多奖励掩盖问题。

## 阶段4：仅在基线不足时调整通用接触反应

**进入条件**：第3阶段配置/动力学正常，但出现可重复的坑壁停滞或抬轮不足。

优先按状态检查已有姿态/动作代价是否妨碍必要运动，尝试有针对性的放松。
若仍缺少探索信号，再研究最小通用扩展：“有移动命令＋持续水平阻挡接触”时，
给予短时、限幅的抬轮/世界z向上运动激励；不依赖固定x坐标或绝对坑深。

不能将 `lin_vel_z_l2` 翻成正权冒充上抬奖，因为它是机体系z速度平方，连下落也会奖励。
普通承重接触也不能充当撞墙；防止原地跳跃刷分，并观察跨时间是否获得有效前进，
不要求抬升瞬间一定高速向前。若动作/actor要用接触状态，应有部署可实现的估计来源。

**验收**：保持第3阶段为对照，每次只改变一组机制，比较通过率、停滞、跌倒与平地滚动。
无收益则撤销，不继续叠加。同样的地形与评估条件下再判断历史估计器是否值得增加，
不在这一阶段同时替换PPO算法。

## 阶段5：完整训练、泛化评估与后续扩展

**进入条件**：低阶通过可靠，课程能够推进，回放行为符合轮腿协同且无明显刷分。

- 再扩大到显存允许的完整规模；4096环境不是必须目标，不能重复在已有显存占用时硬开。
- 10000 iterations作为与旧基线比较的参考，记录环境数×rollout×迭代数的样本量；
  以固定高度评估与课程趋势决定继续训练，不仅看总reward。
- 为同一配置的长训允许从其checkpoint继续；观测、资产或奖励目标变更则另开实验，
  明确是重训或有意微调，不混成同一基线。
- 逐步恢复域随机化、指令范围和出生扰动，避免与首次学爬沿同时引入全部难度。
- 在独立的直线单级高台上评估5/10/15/20/30 cm等固定高度；每高度足够多次reset，
  建议最终至少100次并记录样本数，有条件再做多随机种子。排除坑角借力与训练场景记忆。

验收依据是固定高度上的通过率/支撑稳定性、速度跟踪、跌倒/停滞和对资产版本一致的
回放。完成前不宣称已达300 mm；更高目标另做运动学与驱动可行性评估。
