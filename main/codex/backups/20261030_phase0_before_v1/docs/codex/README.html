7. 更新和证据规则#

最新用户说明优先。当前实现以实际源码/验证为准；规划参数不能反推为已实现。 CURRENT_STATUS写当前，DECISIONS保留依据和替代关系，EXPERIMENT_LOG保留原始数据并在 旧解释旁标明更正。研究报告、早期审计和旧操作示例均按各自日期理解。 用户在新聊天明确要求开始实施时，可以按阶段0继续，不必把本轮“只审文档”当作永久禁止开发。

新增/移动资料应更新本页与HANDOFF的链接，并检查文件存在；历史快照不跟随本轮改写。 本轮校验记录见 CONTEXT_LINK_CHECK_20261030.json： 仅验证本地链接/目录、关键备份和业务文件未变，未验证网络URL、远程文件或训练成功率。
